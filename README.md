# RiskLens

A simple web app that checks whether a URL looks like a phishing site.

You type in a URL, and it returns:
- A **risk score** (0–5)
- A **risk level** — Safe / Suspicious / Dangerous
- A short **explanation** of which URL characteristics contributed to that score

It works purely by analyzing the **text of the URL itself** (length, symbols, keywords, structure, etc.) — it does not visit, crawl, or render the target website.

---

## How it works

User types a URL into the React app
->
Frontend sends POST request to backend (/check) with { "url": "..." }
->
Backend extracts numeric features from the URL (features.py)
->
Backend runs those features through a trained RandomForest model (model.pkl)
->
Backend converts the prediction into a score (0–5), level, and explanation
->
Frontend displays the result

## Notes

- dataset.csv currently contains synthetic placeholder data (see generate_dataset.py). Swap it for a real phishing-URL dataset (same url,label format) and re-run train_model.py to retrain on real data.
- No authentication, no database, no history storage. One input, one action, one result.

## Known Limitations

Because this is an open-source project, the feature-extraction logic in `features.py` is publicly visible. A motivated attacker could theoretically reverse-engineer the model's signals (keyword list, numeric thresholds, known-shortener list) and craft URLs that avoid every flagged feature. That is an inherent trade-off of open-source security tooling, not a bug.
